# README
This repository has two projects. Both are for a web app that generate colour palettes. One is done using Vue and the other is done using React.

## Running the Vue Project
To run the Vue project, simply open your terminal change directory to `vue_colour_palette_generator` and then run the following commands in order:
* `npm install` - This will install all the dependencies for the project.
* `npm run dev` - This will start the development server. You can view the app in your browser from the link provided in the terminal.

## Running the React Project
To run the React project, simply open your terminal change directory to `react_colour_palette_generator` and then run the following commands in order:
* `npm install` - This will install all the dependencies for the project.
* `npm run dev` - This will start the development server. You can view the app in your browser from the link provided in the terminal.

## Acknowledgements:
* [Colormind.io api](http://colormind.io/) - Colour palette generator that uses deep learning. It has a REST API so its features can be accessed for the app.
